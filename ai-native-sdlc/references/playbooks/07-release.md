# 07 배포

- **입력** 배포 리비전의 검증 결과와 필요한 수락 근거, 배포 권한, 해당하는 이행·복구 계획.
- **Ready** 버전, 환경·설정, 호환성과 이행, 중단 기준, 복구와 관측 준비를 확인한다. 승인된 범위에서 배포한다.
- **배포 후** Smoke, 핵심 사용자 흐름, 지표와 필요시 이행·단계적 노출 결과를 확인한다.
- 배포 전 준비 판정과 배포 후 관측을 분리한다. 실제 버전·환경·시간과 중단·복구 결과를 연결한다.
- 장애 시 중단·안정화한다. 원인 지점 수정 → 영향 검증 → Ready 재판정.
- **기록** 준비 판정, 실제 시각과 버전, 검사와 복구 증거를 기존 배포 기록에 남긴다. 별도 기록이 필요하면 [배포 기록 틀](../../assets/templates/release.md)을 사용한다. 운영 설계는 03-G를 참고한다.
- **종료** [Ready와 G7](../lifecycle.md#단계별-종료-조건)을 각각 판정한다. 운영 관측이나 후속 결정이 범위에 포함되면 08에 연결한다.
- 장애 대응 중 기존 승인 버전 복구는 부여된 사고 대응 권한과 절차를 따른다. 복구 대상, 권한, 시각과 실제 상태를 배포 기록에 연결한다. 신규 수정 배포 전에 관련 검증과 Ready를 확인한다.
