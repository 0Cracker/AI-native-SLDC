# 07 배포

- **입력** G6 수락 결과, 배포 리비전과 권한, 이행·복구 계획.
- **Ready** 버전, 환경·설정, 호환성과 이행, 중단 기준, 복구와 관측 준비를 확인한다. 승인된 범위에서 배포한다.
- **배포 후** Smoke, 핵심 사용자 흐름, 지표와 필요시 이행·단계적 노출 결과를 확인한다.
- 배포 전 준비 판정과 배포 후 관측을 분리한다. 실제 버전·환경·시간과 중단·복구 결과를 연결한다.
- 장애 시 중단·안정화한다. 원인 지점 수정 → 영향 검증 → Ready 재판정.
- **기록** [배포 기록](../../assets/templates/release.md)에 준비·실제 시각·버전·검사·복구 증거. 운영 설계는 03-G 참조.
- **전환** [Ready·G7](../lifecycle.md#단계별-종료-조건)을 각각 판정한다. G7 충족 후 08.
- 장애 대응 중 기존 승인 버전 복구는 부여된 사고 대응 권한과 절차를 따른다. 복구 대상, 권한, 시각과 실제 상태를 배포 기록에 연결한다. 신규 수정 배포는 G6와 Ready를 거친다.
