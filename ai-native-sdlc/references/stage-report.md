# 단계 마감 HTML 보고

- [HTML 작성 틀](../assets/templates/stage-report.html)을 사용한다. 단계와 범위, 판정, 핵심 결과, 산출물과 실행 근거, 남은 위험·차단, 다음 행동을 담는다. 화면에서 관계와 순서는 간단한 흐름으로, 비교와 판정은 표로 표현한다.
- 기존 프로젝트의 보고 경로를 우선한다. 없으면 Feature 폴더 아래 `reports/<stage>-<scope>-<round>.html`에 저장한다. 단계는 `00`~`08`을 사용하되 06은 `06a`·`06b`로 구분한다. 범위는 `feature`, Increment 또는 Task ID다. 차수는 `01`부터 올려 이전 보고를 보존한다. 예를 들어 `reports/05-t003-02.html`은 T003의 두 번째 05 보고다.
- Feature 폴더를 만들지 않는 축약 경로는 기존 변경 정본과 같은 위치의 `reports/`를 사용하고 범위에 변경 ID를 넣는다.
- 원본 문서의 판정과 리비전을 그대로 참조한다. 파일 링크는 보고 파일 기준 상대 경로를 사용하고, 외부 실행 증거는 접근 가능한 링크로 연결한다. HTML은 보고 시점의 요약이다. 변경이나 재검증 시 정본을 먼저 갱신한다.
- 데이터와 문구는 HTML 텍스트로 이스케이프한다. 링크는 실제 상대 경로나 승인된 HTTPS 주소를 사용한다. 적용하지 않는 표·목록은 제거하고 빈 자리 표시자를 확인한다.
- 지원되는 환경에서는 HTML 미리보기를 보여준다. 채팅에 삽입할 수 없으면 저장한 HTML 파일의 링크와 판정·다음 행동을 함께 전달한다. 실제 판정의 근거는 채팅에서도 찾을 수 있게 한다.
- 가능하면 생성한 HTML을 열어 판정·링크와 좁은 화면의 배치를 확인한다. 독자에 맞춘 설명은 [스킬의 마감 보고 규칙](../SKILL.md#단계별-최종-마감-보고)을 따른다.
