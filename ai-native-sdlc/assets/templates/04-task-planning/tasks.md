# 04 작업 계획과 진행 상태

- Feature / Increment / 목표와 전달할 결과
- Increment별로 아래 블록을 추가한다. 이전 작업 상태와 판정·증거는 보존한다.
- 요구·아키텍처·상세 설계·테스트 명세 링크
- 시작 전 준비할 계약, 환경, 테스트 데이터와 접근 조건

## 구현 작업과 완료 조건

| Task ID | 목표와 요구·설계·계약 ID | 선행 Task | 수정할 파일·계약과 소유자 | 완료할 코드·산출물 | 통과할 검사 ID | 상태와 G5 증거 링크 |
|---|---|---|---|---|---|---|

## 검증 담당과 통합 순서

| Task와 검사 ID | 테스트 작성 담당과 쓰기 범위 | 구현 담당과 쓰기 범위 | 선행 조건과 인계 근거 |
|---|---|---|---|

가능하면 테스트 작성자와 구현자를 나눈다. 한 담당이 수행하면 같은 담당을 기록하고, 승인된 기대값의 출처와 기능 코드 변경 전 검증 근거를 구분한다.

| Increment 통합 순서 | 합칠 산출물과 선행 Task | 06a 검사 ID 또는 G3의 생략 근거 |
|---|---|---|

| 병렬 작업 묶음, 해당 시 | 독립적으로 진행할 수 있는 근거 | 공유 파일·계약과 조정 방법 |
|---|---|---|
