# 05~06 검증 기록

- Feature / Increment / Task / 검증 환경과 계약 버전
- 대상 코드 리비전 / 적용한 테스트 명세 / 실행 담당과 독립 검증 범위

## 05 Task 실행 근거

| Task·검사 ID와 방식 | 테스트 작성·구현 담당 | 변경 전 리비전·명령·결과·증거, 실패 이유나 기준선 | 변경 후 리비전·명령·결과·증거와 회귀 | 실행 환경 또는 공통 환경 참조 | G5 판정과 차단 사유 |
|---|---|---|---|---|---|

- 결정적 변경은 승인된 기대값으로 의도한 실패를 재현했는지 기록한다. 환경 오류는 별도로 기록한다.
- 리팩터링은 동등성, 확률적 변경은 기준선·반복 조건·평가 결과를 연결한다.
- 테스트 구동 준비가 필요했다면 준비 범위와 리비전을 기록한다. 의도한 실패를 확인할 수 없으면 이유와 차단 상태를 적고, 승인된 예외가 있으면 승인 근거와 대체 증거를 연결한다.

## 06a Increment 통합

| Increment·통합 검사 ID | 실제 연결 범위와 선행 Task | 환경·리비전·명령 | 기대 기준 참조 | 실제 결과와 증거 | 판정 |
|---|---|---|---|---|---|

- Increment·대상 리비전 / 06a 판정과 근거 / 통합 미적용 시 G3 생략 근거와 수행한 나머지 검사

## 06b Feature 수락

- 수락 대상 리비전과 환경 / G5·06a 증거의 적용 범위

| 인수 조건·검사 ID | 기대 기준 참조 | 실제 결과와 증거 | 통과·실패·차단·승인된 예외 |
|---|---|---|---|

- 독립 검증 적용 여부와 담당·범위·증거 / 수락 판정과 결정 근거
- 결함·잔여 위험·승인된 예외 / 복귀 단계·수정 리비전·재검증 / 다음 행동
