# 03-F 보안과 개인정보

- **적용** 신뢰 경계, 권한, 민감정보 또는 외부 실행 변경.
- **입력** 관련 요구·인수 조건, 상위 설계와 현행 근거.
- 보호 대상, 분류, 행위자와 신뢰 경계를 식별하고 데이터의 수집, 이동과 저장을 확인한다. 복잡한 경로는 필요에 따라 그림으로 설명한다.
- 오용과 실패에 대응하는 권한, 거부, 감사·보존, 암호화·마스킹을 정한다.
- 권한 거부, 격리, 우회·유출 검사를 연결한다. 미결 권한과 위험은 사용자나 책임자에게 확인한다.
- **산출물** `designs/D001-*.md`, [작성 틀](../../assets/templates/security-design.md), [그림 예시](../../assets/templates/trust-boundary.mmd). [그림 규칙](../diagram-policy.md)을 따른다.
- **완료** 변경 경계마다 통제, 실패 행동과 검사 근거가 연결된다.
