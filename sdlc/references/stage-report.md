# HTML 보고서 작성 가이드

- 사용자 요청이나 프로젝트 규칙에 따라 HTML로 보고할 때 적용한다. 여러 단계는 한 보고서에 묶을 수 있다.
- [HTML 작성 틀](../assets/templates/stage-report.html)에 요청한 범위, 판정, 핵심 결과, 실행 근거, 남은 위험과 다음 행동을 담는다. 관계와 순서는 흐름으로, 비교와 판정은 표로 보여준다.
- 지정 경로와 기존 보고 관례를 우선한다. 별도 관례가 없고 프로젝트 안에 보관해야 하면 관련 기록 아래 `reports/`에 둔다. 범위와 차수를 이름에 넣어 기존 보고서를 보존한다.
- 원본 문서의 판정과 리비전을 그대로 참조한다. 파일 링크는 보고 파일 기준 상대 경로를 사용하고, 외부 실행 증거는 접근 가능한 링크로 연결한다. HTML은 보고 시점의 요약이다. 변경이나 재검증 시 정본을 먼저 갱신한다.
- 데이터와 문구는 HTML 텍스트로 이스케이프한다. 링크는 실제 상대 경로나 승인된 HTTPS 주소를 사용한다. 적용하지 않는 표·목록은 제거하고 빈 자리 표시자를 확인한다.
- 지원되는 환경에서는 HTML 미리보기를 보여준다. 채팅에 삽입할 수 없으면 저장한 HTML 파일의 링크와 판정·다음 행동을 함께 전달한다. 실제 판정의 근거는 채팅에서도 찾을 수 있게 한다.
- 가능하면 생성한 HTML을 열어 판정, 링크와 좁은 화면의 배치를 확인한다. 독자에 맞춘 설명은 [스킬의 마감 보고 규칙](../SKILL.md#마감-보고)을 따른다.
