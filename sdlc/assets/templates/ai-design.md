# AI, Agent와 검색 설계

- 해결할 작업과 현재 한계 / 선택한 구성과 대안의 절충 / 보장할 안전 조건

- Feature / Increment / 상세 설계 ID / 영역 코드
- 상위 요구·아키텍처 ID와 링크 / 관련 설계·검사 ID

- 사용자 결과 / 규칙 기반 대안 / AI를 사용하는 이유
- 모델·프롬프트·검색 인덱스 버전 / 흐름도 원본 / 주요 계약
- 각 Agent와 Tool의 책임, 권한, 실행 전 확인 조건
- 데이터 출처, 검색 필터, 근거 표시, 데이터 보존
- 근거 없음, 모델 오류, 유해 입력, 권한 거부 시 중단·Fallback

|---|---|---|---|---|---|
