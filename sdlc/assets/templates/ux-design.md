# 화면과 사용자 흐름 설계

- 현재 사용자 마찰과 근거 / 선택한 상호작용과 이유 / 유지할 경로

- Feature / Increment / 상세 설계 ID / 영역 코드
- 상위 요구·아키텍처 ID와 링크 / 관련 설계·검사 ID

- 사용자 목표 / 진입 경로 / 연결된 요구·인수 조건
- 흐름도, 와이어프레임 또는 화면 상태 원본

| 화면·상태 | 진입 조건 | 사용자 조작 | 표시와 피드백 | 다음 상태·복구 | 검사 ID |
|---|---|---|---|---|---|

- 입력 오류, 빈 상태, 로딩, 권한 부족과 재시도, 해당 시
- 키보드 순서와 포커스, 접근 가능한 이름, 반응형 제약
- 데이터 계약과 권한 / 승인 필요한 문구나 경험
