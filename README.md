# AI-Native SDLC

`ai-native-sdlc`는 기능 개발, 버그 수정, 리팩터링, 데이터 이행, 배포에 사용하는 스킬입니다. 요청에서 요구사항, 설계, 구현 작업, 검증 결과까지 근거를 연결해 작업을 이어갈 수 있게 돕습니다.

## 어떻게 진행하나요?

**요청 정의 → 요구사항 → 아키텍처 → 상세 설계 → 작업 계획 → 구현 → 검증과 수락 → 필요 시 배포와 운영**

- 범위와 기대 동작이 모호하면 먼저 확인합니다. 작은 변경은 유효한 기존 문서와 테스트를 재사용합니다.
- 설계에서 영향을 받는 영역은 편집 가능한 다이어그램으로 기록하거나 기존 그림을 연결합니다.
- 단계마다 통과 조건과 증거를 확인하고, 마감 보고는 HTML로 전달합니다. 작업을 이어갈 때는 변경된 결정과 다시 확인할 검사를 찾을 수 있습니다.
